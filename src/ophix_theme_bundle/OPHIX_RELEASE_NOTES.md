# Ophix Theme Bundle Release Notes

## 2026.10.11.01

- Refreshed all 9 bundled themes from current server exports — each theme now carries
  every `Theme` model field added since the initial release (action button colors,
  disabled-row color, tab border radius, body text color, related-modal dark opacity,
  and others), instead of silently falling back to model defaults for fields that
  didn't exist yet when the bundle was first built.
- Renamed the **Blooberry** theme to **Bloobs** (also updates its logo asset).
- Raised the `ophix-admin-interface` dependency floor to `2026.09.07.01` — the version
  that introduced the last of the newly-included fields.

## 2026.07.11.01

- Initial release. Bundles 9 demonstration color-palette themes: Apurplexy, Blooberry,
  Chocolatte, Eucalypty, Ice Queen, Quicksilver, Sakura, Stone Cold, Tealifique.
